# shellui.ai

Agent onboarding for [Shellui](https://shellui.com) — Netlify-style `fetch https://shellui.ai`.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploys to GitHub Pages on push to `main` (custom domain `shellui.ai`).
